🏖️ Wisata API Tester

📋 List & Search

GET /api/dolanbanyumas/wisata

Get wisata dengan pagination dan filter

GET /api/dolanbanyumas/wisata-all

Get semua wisata tanpa pagination (untuk map/mobile)

🔍 Detail & Filter

GET /api/dolanbanyumas/wisata/{id}

Get detail wisata berdasarkan ID

GET /api/dolanbanyumas/wisata/kategori/{kategori}

Get wisata berdasarkan kategori

GET /api/dolanbanyumas/wisata-categories

Get daftar kategori wisata yang tersedia
